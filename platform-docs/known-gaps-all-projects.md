# ช่องว่างที่พบแต่ยังไม่ได้แก้ — รวมทุกโปรเจกต์

เอกสารนี้เป็น **living list** — รวมช่องว่าง/จุดอ่อนที่เจอระหว่างคุยงาน
แต่ละโปรเจกต์ไว้ที่เดียว (เดิมกระจายอยู่คนละ section ในแต่ละ CLAUDE.md)
เพื่อให้ตรวจทบทวนเป็นรอบๆ ได้ง่ายขึ้น ไม่ใช่เจอแล้วลืม

**วิธีใช้:** เจอช่องว่างใหม่ระหว่างคุยงานโปรเจกต์ไหน → เพิ่มลงลิสต์นี้
(พร้อมลิงก์ไป section เต็มใน CLAUDE.md ของโปรเจกต์นั้นถ้ามี) — พอแก้เสร็จ
จริงแล้ว ให้ย้ายไปเป็น ✅ หรือลบออก อย่าลืมอัปเดตวันที่ท้ายไฟล์ด้วย

**อัปเดตล่าสุด:** 2026-09-21

  หายเมื่อ deploy ใหม่ (Render free tier ephemeral disk) — ยังไม่แก้
  รอตัดสินใจเรื่องเสียเงิน (persistent disk / Cloudinary)
- **PIN เก็บเป็น plain text ทุกจุด** (adminEditPin, dataResetPin, login
  PIN ในชีต Directory) — มี TODO ชัดเจนแล้วให้ hash ด้วย bcrypt ก่อนขาย
  ต่อให้ลูกค้ารายที่ 2 จริงจัง ยังไม่เริ่มทำ
- **Voice/mic ผ่าน LINE AI ยังใช้ไม่ได้** — รอคุณต้นให้ `OPENAI_API_KEY`
- **ไม่มีระบบ migration runner อัตโนมัติข้ามทุกตึก** — สคีมาใหม่ต้อง
  ไล่รันเองทีละตึก เสี่ยงลืมตึกใดตึกหนึ่ง (เกิดมาแล้วหลายครั้ง)
- **`MASTER_RECOVERY_PIN` เป็นค่าคงที่ hardcode เดียวใช้ร่วมทุกตึก** —
  ต้องย้ายเป็น per-deployment secret ถ้าจะขายต่อจริง
- **ห้อง 1, 2 และอื่นๆ ในบ้านเลขที่1873 ยังค้างค่ามิเตอร์น้ำที่ยังไม่ได้
  คาลิเบรตใหม่** หลังแก้บั๊ก root-cause แล้ว (ตัวเลขต่ำกว่า waterPrev
  ซึ่งเป็นไปไม่ได้จริง)
- **ห้องรายละเอียด (room detail panel) "บิลล่าสุด" ยังโชว์เดือนปัจจุบัน
  ของระบบ (global) แทนเดือนบิลล่าสุดจริงของห้องนั้น** — จุดเดียวที่ยัง
  ไม่ได้แก้จาก 4 จุดที่เจอบั๊กเดียวกัน
- **กลไก resend ใบเสร็จที่ยังไม่ยืนยัน (`receiptRetryEnabled`) ปิดไว้**
  หลังเจอ off-by-one bug — ยังไม่ตัดสินใจว่าจะแก้เลขที่ถูกต้องแล้วเปิดใหม่
  เมื่อไหร่
- **Android APK ("android-app/") ถูกทิ้งไว้เฉยๆ ไม่ได้ลบ** หลังเปลี่ยนไป
  ใช้ PWA แทน — ยังไม่มีคำสั่งชัดเจนให้รื้อทิ้ง
